# Beckett

A private family app for Beckett’s day and growth, built on the generated shadcn/Vite monorepo in [`baby-tracker/`](baby-tracker/).

```sh
cd baby-tracker
pnpm install
pnpm dev:demo     # explicitly labeled, local sample data; no account needed
```

For real persistence, Google sign-in, AI interpretation, local checks and deployment, see [the setup guide](baby-tracker/README.md).

Vercel’s **Root Directory must be `baby-tracker`**. No GitHub test workflow is required; checks run locally.
